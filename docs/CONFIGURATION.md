# 配置说明

配置由 Fzzy Config 管理，文件为游戏或服务器目录下的 `config/buildupmobtweaks/main.toml`，当前格式版本为 **13**。

## 怎样修改

游戏内可使用 Fzzy Config 的 `/configure buildupmobtweaks.main` 配置入口；服务器设置默认需要管理员权限等级4。多人游戏的生物规则以服务器设置为准，客户端自己的关闭值不能覆盖服务器规则。

直接编辑 TOML 时，先停止游戏或服务器，备份文件后再修改并重启。原版 `/reload` 用于数据包，不等于重读磁盘配置。不要手动改写自动生成的 `version`，降级前备份配置和存档。连接服务器时，同步的配置可能写入客户端本地文件；希望保留单人设置时先备份。

## 常用分组

| 分组 | 用途 |
| --- | --- |
| `general.enabled` | Mod 行为总开关，默认开启 |
| `hostile.skeleton` / `zombie` / `drowned` / `raid` / `vex` | 相应敌对生物的基础行为与参数 |
| `hostile.extended` | 其他已接入的独立能力、感知、运动和视觉选项 |
| `passive` | 动物、宠物、嗅探兽和雪傀儡等独立行为 |
| `equipment` | 出生装备池分配，独立于高级能力抽取 |
| `traits.enabled` | 已接入高级出生能力的主开关；不是给所有生物统一随机加技能 |

各项行为开关默认开启，但有概率或触发条件的能力不会因此自动出现在每个个体上。概率以千分比表示：100为10%，1000为100%。普通装备池分配概率默认100；各类特殊能力使用各自参数，不共用该值。冷却等以tick表示，正常20TPS下20tick约为1秒。

## 修改后何时生效

- **行为开关**：影响后续执行，已有动作或弹体会按各自规则结束/清理；不是瞬间回退整个存档。
- **出生概率与装备池**：一般只影响以后出生的生物。旧实体不重新抽奖，不补发已经消耗或丢失的物品。
- **冷却数值**：已启动的动作预算可能保留原期限，新数值在后续动作使用。
- **关闭视觉**：控制相关表现，不撤销已经受到的伤害或原版状态效果。

## 标为“未生效”的选项

为兼容旧配置，保留了部分历史字段，但开启它们不会启用未加入的玩法。例如亡灵马日烧、敌对生物休息、部分不祥雪球与旧组合技能目前未接入。旧瞄准/危地/尸壳矛别名由现有行为覆盖，不是第二套可以叠加的修复。

Common/Advanced/Rare演示Marker及其历史权重不参与正式生物抽取。`traits.enabled`本身仍管理已接入的高级出生能力，不能因为Marker未生效就认为该主开关无效。保留旧设置值不代表该字段已有玩法。

建议先使用默认设置，遇到具体问题时只关闭对应行为，记录版本、Mod清单和复现条件。更细的实体排除方法见[兼容说明](COMPATIBILITY.md)。[返回首页](../README.md)
