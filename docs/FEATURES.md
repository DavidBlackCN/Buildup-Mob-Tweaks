# 功能介绍

本页介绍当前已接入的玩法。独立开关和概率见[配置说明](CONFIGURATION.md)；没有列出的上游玩法不代表已经加入。

## 敌对生物

- **掠夺者**：在合适距离切换实际持有的弩和近战武器，远程阶段会调整位置；脱战受伤时可消耗背包里的食物恢复。食物并非每只都有，重新读档不会补发。
- **骷髅家族**：安全横移和远近武器切换、适用情况下的狙击与寻荫；同类射手可错峰拉弓。普通骷髅、流浪者、沼骸、凋灵骷髅和焦骸有各自适用行为，不能将某一变种的能力当作全部骷髅的默认技能。部分个体可生成为半尺寸幼体。
- **流浪者、沼骸、焦骸与凋灵骷髅**：选定个体可有翻转投球、退避孢子、旋转闪避或特殊头颅弹等能力，受各自出生条件和冷却限制。
- **僵尸家族**：已有盾牌可用于格挡；抽中门盾特性的个体使用真实门物品和有耐久的门板展示。部分幼年鸡骑士会扑击，合适坐骑上的生物还有专项动作。
- **尸壳**：在合适沙层和允许生物破坏的条件下下潜、换位并上浮，不会在任意方块上潜地。
- **溺尸**：把手中实际三叉戟投出并寻回；符合条件且有鱼竿时可抛竿拉拽。三叉戟不是额外复制的备用道具。
- **职业僵尸村民与僵尸猪灵**：已选定的职业/武器组合可用弩、鱼竿或消耗药水支援。换职业、治愈或读档不会反复补发装备。
- **女巫、唤魔者、恼鬼**：保留原版选药与施法基础，加入可观察的预告、有限冷却或数量限制。特殊火球和图腾是条件式能力，不是所有唤魔者的常驻技能。恼鬼对正值投射物伤害有独立弱点开关。
- **幻术师与卫道士**：有界换位、射击停顿、分身箭及限定支援；分身箭有预算，不是每次射击都齐射。骑乘树保护只针对当前同一坐骑关系，不提供通用友军免伤。
- **恶魂、烈焰人、蠹虫与末影人**：分别有选定的慢弹/预告、移动与难度相关齐射、躲藏/援军反馈、有限连击等行为。
- **苦力怕、蜘蛛与旋风人**：保留伤害和原版基础行为，加入选定的嵌箭/命中反馈、捕食目标或起跳/落地爆发；旋风人的可选散弹总计三发，额外弹与爆发共用冷却预算。

## 动物与互动

- 鱿鱼受攻击时可释放防御墨汁；荧光鱿鱼的注视互动需要实际距离和视线条件。
- 鸡会逃离适用威胁，动物惊慌可以在有限范围内传播。潜行接近只影响选定的原生动物避让，不会让所有生物忽略玩家。
- 有主宠物在满足条件时缓慢恢复；猫可避开真实弹体，但并不因此免疫伤害。
- 吹山羊角可在有限范围内吸引适用敌对生物；流浪商人有受击自卫反馈。
- 成年嗅探兽的探索需要潜行玩家持有适用物品，只查询已加载区域，不能把它当成无限距离的定位工具。
- 雪傀儡可有南瓜归还、戴南瓜时额外10点临时护甲、限定远程扫射及交替手投球表现。

## 共同行为

选定生物的主动发现会受失明、隐身、潜行或发光等条件影响；发光不等于能隔墙攻击。近战效果节奏、安全起跳与横移退出都有独立开关。燃烧、冰冻和部分弹体视觉可以单独关闭。

装备与能力不会因每次加载世界重新抽取。出生概率、特殊装备、目标和地形条件各自独立；改变出生概率通常只影响新生物。已有物品仍按实际所有权处理，不会因读档或关闭某项能力凭空补发。

本版本未加入 Boss AI 接管、上游新增附魔、独立装备成长、完整村民生活系统及未列明的史莱姆/幻翼玩法。[返回首页](../README.md)
