# 职业村民工作（实验功能）

开启村民核心后，可以单独试用职业工作。工作使用原版工作时段和已绑定的工作站；交易、睡眠、逃跑和袭击响应仍由原版处理。农夫收获与补种继续使用[原来的农夫入口](FARMER_INTELLIGENCE.md)。

## 启用与材料

在 `config/buildupmobtweaks/main.toml` 或 Fzzy Config 中启用 `villagers.enabled`、`villagers.schedule_coordination` 和 `villagers.professions.enabled`。新职业工作总开关默认 **false**；旧存档更新后不会自行开启。

| 活动 | 条件和真实材料 | 结果 |
| --- | --- | --- |
| 村民进食 | 受伤、主手空、库存有面包／胡萝卜／马铃薯／甜菜根 | 完成进食后扣一个食物，按该食物营养值回血；临时显示食物不进入真实手部 |
| 渔夫钓鱼 | 工作站为木桶，主手有真实钓竿，附近有水和可站立岸边 | 可从桶顶发现低两格水面并走到岸边，真正抛出浮漂，等待原版咬钩；一次鱼类战利品表结算，钓竿损耗1，优先放入自身库存 |
| 牧羊人剪毛 | 工作站为织布机，主手有真实剪刀，附近有成年且有毛的羊 | 原版剪毛与羊毛掉落，剪刀损耗1 |
| 牧师治疗 | 酿造台，主手空，库存有普通或强效的喷溅治疗药水 | 投出实际药水，消耗一瓶；仅作用于本次选定的受伤村民 |
| 三类铁匠修理 | 对应工作站，库存有铁锭，附近有受伤铁傀儡 | 一铁锭恢复25生命；三职业共用同一个修理活动 |
| 农夫喂幼体 | 额外开启 `baby_feeding`，库存有目标动物接受的食物 | 消耗一个食物，使用原版幼体成长加速；与收获互斥 |

工作不会给村民自动配发钓竿、剪刀、药水或铁锭。管理员定向测试时可用原版 `/item replace` 配备主手工具；库存材料由原版物品过程或测试命令准备。正常游戏目前没有新运输／补给系统。

所有13种原版职业均有工作去向：农夫照料作物；图书管理员阅读；制图师短途观察并返回；制箭师整理箭支；石匠、皮革匠、屠夫和三类铁匠在工作站进行相应持物／声音动作；牧师、渔夫、牧羊人在没有资源动作时也可进行日常工作。普通工作动作不生产物品。无业、傻子与幼年村民没有职业工作；受伤成年村民的进食独立于职业工作时段。

## 独立选项

下表键均位于 `villagers.professions`；子项为 true 时仍需启用总开关。

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `enabled` | false | 新职业工作与进食总开关 |
| `external_control` | false | 让出本模块全部活动 |
| `daily_routines` | true | 工作站日常动作 |
| `self_heal` / `fishing` / `shearing` / `cleric_healing` / `golem_repair` | true | 分别控制对应活动 |
| `profession_switches.<职业名>` | true | 控制该职业的新工作；farmer 不控制原来的收获补种；进食独立控制 |
| `baby_feeding` | false | 农夫喂幼年动物 |
| `wool_pickup` | false | 只拾取本次剪毛刚产生的羊毛；普通漏斗仍按原版收集掉落 |
| `archery_training` | false | 制箭师使用真实弓箭向现有靶子射击；箭不可拾取、不伤实体，命中可触发靶子信号 |
| `decoration_frames` / `decoration_stands` / `decoration_blocks` | false | 真实付费材料展示，见下节 |
| `protection_required` | false | 资源操作要求已注册权限适配；装饰始终要求权限适配 |
| `scan_interval` | 60 | 职业候选检查间隔，20～1200刻，按村民错峰 |
| `action_cooldown` | 200 | 开始及实际结算时记录的活动冷却，20～2400刻 |
| `world_scan_budget` | 512 | 每世界每刻的候选／方块检查预算，64～4096；不是服务器总实体遍历次数的硬上限 |

20TPS 时20刻约为1秒。原版选择工作动作也有等待，冷却结束不代表立刻执行。开关不会清空冷却。

## 可选真实展示

展示消耗村民真实库存中的普通材料，只放在工作站附近已经加载的空位置。图书管理员／制图师／制箭师可放物品框，消耗一个框及一本书／空地图／一支箭；三类铁匠／皮革匠可放盔甲架，消耗一个架及对应的普通铁头盔／铁剑／铁镐／皮革胸甲。石匠目前只摆放消耗实际饰纹陶罐的展示方块。

此功能始终要求 `InteractionPolicy` 的权限适配明确允许；只打开配置而没有适配器时保持暂停。本版没有随包附带已经实测的第三方领地适配器。

每个村民、每种展示最多一份归属记录。关功能、换工作站或换职业后，只收回标记与内容仍完全一致的自身展示，返还当前真实道具及已支付的载体材料。玩家修改过的展示会解除归属并留在世界中；丢失的展示不会按旧记录补发。替换成外观相同的新陶罐也不会被误删。

展示生命周期仍有一项限制：村民死亡／转化时，所在区块已加载且权限允许的展示会清理；若展示区块未加载或权限后来拒绝，展示保留，不强制加载、不凭记录补发。管理员应在移除主人前先关闭展示并让相关区块加载完成。此场景尚没有全世界孤立展示回收器。任意石块的同外观替换无法可靠证明归属，因此本版没有开放自由石材摆放。

## 让位、查询与保存

用 `/buildupmobtweaks villager <实体>` 查看原版活动、支持级别、当前活动／适配器、开始和结算计数及保存冷却。支持级别是注册状态，不是第三方兼容认证。该命令只读。

实体标签可定向让位：

| 标签 | 用途 |
| --- | --- |
| `buildupmobtweaks:profession_external` | 让出该村民的新职业模块 |
| `buildupmobtweaks:disable_villager_work` | 停用该村民的新职业模块 |
| `buildupmobtweaks:disable_work/buildupmobtweaks:fish` | 示例：停用该村民钓鱼，末尾换为实际活动 ID |
| `buildupmobtweaks:disable_adapter/buildupmobtweaks:vanilla/fisherman` | 示例：让出渔夫适配器 |

Core 的既有排除标签继续生效；Farmer 的 external_control 仍控制原来的农业工作及额外喂幼体。未知职业保留原版工作，不猜测其机制。第三方替换整个 Brain 或竞争同一资源时，应由整合包明确负责方，不能靠自动判断保证兼容。

新职业冷却、目标冷却、展示归属与原版库存分别保存；原来的 `farmer_work`、Trait 和僵尸村民职业战斗数据不合并。读档不会继续一个旧投掷／捕鱼动作；未知版本原始数据保留并暂停相关工作。

当前 NPC 钓鱼只使用原版鱼类表，没有玩家钓鱼经验、宝藏和附魔加成适配。自动屠宰、成年繁殖、存桶与额外物流未提供。真实第三方 AI、保护 Mod 和整合包组合尚需分别测试。
