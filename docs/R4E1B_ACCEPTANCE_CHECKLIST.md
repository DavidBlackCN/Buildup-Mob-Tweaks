# R4-E1-b 人工验收清单

本批只含猪灵弩兼容、射后挥手、近距后跳、僵尸猪灵同类仇恨修复。自动证据见 [报告](R4E1B_REBUILD.md)，不替代以下肉眼验收。E1-c/E2/R5 尚未进入。

在废弃测试实例安装 `build/libs/buildup-mob-tweaks-1.0.0.jar` 和 `build/libs/buildup-mob-tweaks-1.0.0-qa.jar`，以及 [QA指南](PHASE1_QA_GUIDE.md) 的现有依赖。正式发布包不包含 QA。使用正常20TPS、普通难度、作弊/owner权限；选择已加载、空旷超平坦测试场，不在正式存档执行。默认配置即可，无需改出生概率。

每场前执行 `/buildupqa cleanup`，然后任选已加载空位置：

```mcfunction
/execute positioned 0 120 0 run buildupqa spawn piglin
/buildupqa check
/buildupqa inspect @e[tag=buildupmobtweaks_qa_fixture,type=minecraft:piglin,limit=1]
```

- [ ] `piglin`：约14秒内主手实际拉弩、射箭扣目标血并挥手；140tick工具把同一把弩转到副手，此后仍从真实副手蓄力/射后挥手，物品数量始终一份。观察蓄力姿势、手臂方向和挥手，不以工具计数代替视觉。
- [ ] `/buildupqa off`：此场只关闭当前实体的弩兼容，不修改全局配置；原版弩仍可发射，可能被原版移到主手，其他独立挥手开关仍生效。`check`/`inspect`显示关闭原因。
- [ ] 清理后用同样位置 `spawn piglin_dodge`：约16秒，初始200tick冷却后工具在实际蓄弩时移近目标，猪灵做一次明显反向跳跃，不循环连跳；箭攻击仍原版调度，检查 dodges=1 和未来 dodge_ready。`off` 后不再启动新后跳，已发生的位移/冷却不会退款。
- [ ] 清理后 `spawn piglin_anger`：源、受害者、同伴共三只僵尸猪灵。真实同类伤害仍扣受害者血，但约3秒内不出现互打或同类 anger 引用；该场“无目标”是保护的预期，不是 QA 失败。
- [ ] 此场 `off` 后再受一次工具安排的同类伤害，受害者恢复原版报复/怒气。同伴开关独立，不能要求仍开启保护的同伴跟着互打；工具不会为了演示关闭整群保护。
- [ ] 各场 `/buildupqa cleanup` 后实体、伙伴、QA所属弹体消失，石地板/屋顶恢复，场景不会在下一场叠加。最多一个会话，1200tick自动超时清理。

补充非强制 QA 检查（记录结果，未执行标 NOT RUN）：

- [ ] 生存攻击普通僵尸猪灵：玩家仇恨与同伴警戒仍成立；切创造/旁观后退出。不要用刷怪蛋的“尚未生气”代替玩家仇恨测试。
- [ ] 猪灵真实拾弩、丢金交易、主/副手换装备、死亡/主世界转换：弩名称/耐久和实际库存总量守恒；有真实外部弩掉落属正常，不应多出隐藏备份。
- [ ] 原生出生默认后跳稀有度另验，不把 QA 强制 birth 的成功率当7%自然概率。自然刷怪器专项本批 NOT RUN。
- [ ] 原门盾 `spawn door`：上下门连续、转向、重登正确，关闭/死亡无残留。原骷髅 `spawn skeleton`：远近切换正常，生成备用木剑不增加满耐久死亡战利品；外部剑正常掉落规则保留。两项自动回归已通过，本批肉眼待复验。
- [ ] 仅正式包、不装 QA 的新实例：普通出生及配置UI可用，无 buildupqa 命令；多人/整合包另记结果。

对已有实体用 `force` / `target` 前先阅读 QA指南：只接受已知且空闲的模块状态，不补真实装备；猪灵 `target` 用真实1点伤害建立原版 Brain 仇恨，**不会恢复血量、耐久或冷却**。请勿选择重要实体。验收反馈建议记录三个scene、实际手/姿势、check输出、游戏版本/Mod列表及是否与单纯正式包一致。

验收后下一批建议为 E1-c 的三项骷髅差异及两个 REPLACE 核验，仍需具体方案批准。本批停在 E1-b。
