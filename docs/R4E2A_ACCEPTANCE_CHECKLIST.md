# R4-E2-a 人工验收清单

以下发行实例/肉眼/GUI目前NOT RUN。使用废弃世界、正式JAR和独立-qa.jar及已有运行依赖，非和平难度，默认概率须非零。不要在生产世界安装QA。

1. `/buildupqa spawn wither_birth`：等待真实拉弓和箭伤，inspect见equipmentLedger outcome=equipped、pool=wither_birth及shots。这是最多512个成年原生候选中的实际命中，不是把弓塞进手里。`off`后原装备和原版射箭保留，耐久增强关闭；`cleanup`恢复场地并退役实体/弹体。
2. `/buildupqa spawn zombified_birth`：观察实际弩及出生账本，保存重载后仍一把。**本批不新增僵尸猪灵远程AI**，不会射弩属E2-b待实施，不记成故障或已通过射击。生成场景不产生额外原版鸡骑士；cleanup后无实体残留。
3. 出生场景仅允许spawn；`force ... <已有实体>`应拒绝重新出生，不覆盖旧物品。概率设0、装备总门关、对应出生门关、无匹配规则时QA应报阻断，不强行发装备或留下地形。
4. 在Fzzy配置中检查两个新千分制概率默认10（1%）、普通池100（10%），旧配置门值保留、版本10。关闭/重开不补发旧怪装备；新凋灵骷髅回到石剑，ZP回到原金剑/金矛。实际刷怪蛋仍随机，不能以少量未见稀有装备认定失败。
5. 用已有装备池示例或自备数据包做空槽分配；先保存实体、重载池，再生新怪，旧物品/耐久/名称不变，新怪采用新规则。首个匹配规则占槽时不尝试后续规则。无效数量/组件/replace/槽位/ID应拒绝该规则，其余合法规则继续生效。
6. 实际装备伤损、移除、死亡和重新登录：无装备补发/复制/隐藏备用；原掉率和mob_drops游戏规则有效。原有命名武器、装备组件及掉率保留，不能把测试中保证掉落的2.0概率误当正式默认。
7. 原`door`和`skeleton`场景复验门盾上下半部/转身，以及生成备用木剑不额外掉落。自然弓/外部装备走正常原版掉率。

每场按inspect/check/off/cleanup记录Mod列表、旧/新配置、数据包、出生来源、前后物品及日志；多人与整合包另行标状态。QA卸载后正式包没有buildupqa命令。

本批停止，不自动进入E2-b/R5/Phase2/3。下一批建议先僵尸猪灵弩AI及职业制箭师弩。
