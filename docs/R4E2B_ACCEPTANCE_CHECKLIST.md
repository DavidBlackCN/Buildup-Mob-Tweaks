1. 运行 `/execute positioned 0 120 0 run buildupqa spawn zombified_crossbow`（中心Z+8，空间需29×29×5）。默认有限原生出生选样；关掉出生发弩或概率为0应报阻断，不能手动补弩。观察实际装填与箭造成伤害，约8秒；7/14/21秒分别移同一把弩至副手、改左惯用手、移回主手（仅空目的槽）。物品不增加。
2. 每场用 `/buildupqa check` 与 `/buildupqa inspect <生成信息中的射手UUID>` 核对实际手、phase、shots/casts/pulls/potions/hook、冷却和运行Goal。用 `/buildupqa off` 等数tick看退出，再 `/buildupqa cleanup`，确认实体/浮漂消失、原场地恢复后开下一场。
3. `spawn fletcher`：仅制箭师职业僵尸村民，真实原生出生弩；主副手装填姿势正确，关单项仍可保留弩和已装弹药，近距原版近战仍有效。已有物品/丢失装备/职业变更不再发第二把。
4. `spawn fisherman`：仅渔夫职业僵尸村民，真实浮漂在约3秒后投出、约6秒后收回；目标被拉动，竿损耗3耐久、线连接正确持竿手、cast模型改变。主副手及左右惯用手、成年与幼体肉眼专项均待复验。
5. `spawn drowned_fishing`：从至多512个原生候选选择真正持竿的溺尸，不手动发竿；上述投竿/牵引正常。另在水中射手与陆地目标、水下目标、遮挡、6格内/13格外、三叉戟在途分别验收；水下目标与在途三叉戟应不抛竿。
6. `spawn cleric`：目标是受伤亡灵，不是铁傀儡；约3秒初始等待和1秒预备后实际药水投出、目标回血，真实瓶子从手中消耗，一场最多一瓶。check说明“已消耗”属于正常，不会无限补发；无敌对目标是预期。活体、满血亡灵和其他玩家不应被自有支援药水误伤。
7. 普通测试世界中，对已有真实装备的对应生物做禁用、换手/换职业、创造/旁观、目标死亡、NoAI、区块卸载/重载、正常保存冷重启。只检查一次物品和冷却守恒，不能通过QA会话重启来声称存档测试（QA正常关服会退场）。已消费药水不补发，在途钩子不继续拉人。
