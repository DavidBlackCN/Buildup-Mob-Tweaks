# R4-E4 人工统一验收清单

本清单用于整 E4 的人工验收，自动测试不代替肉眼验收。请在一次性世界使用本批正式 JAR 与独立 `-qa.jar`，两者版本一致；正式发行时只装正式包。旧 E3 已通过行为继续保留。人工结果目前 **NOT RUN**。

每次先确保加载的空地 25×25×7，无液体/方块实体，非和平；管理员执行 `/buildupqa e4 spawn <场景>`。之后 `check` 查看实际目标、原生 Goal 和弹体记录，`off` 将该场自有生物让位原版，`cleanup` 恢复地形。每服务器只允许一场，1200 tick 自动退出。`off` 是整体让位；单项回退需独立配置或 `buildupmobtweaks:disable_<feature_id>` 标签。控制台生成与静止目标仅是夹具，不验证自然分布。

感知场景先用创造/旁观布置效果、姿态、距离和墙，再切生存；对照时cleanup重建。E4调整初次主动发现，不要求已有仇恨因潜行/隐身/失明立即遗忘；受伤报复保留是预期。stagger的六射手仅冻结普通步行并分开站位，仍有原生Goal、真实拉弓和发箭，避免演示中走位误伤打断同目标对照。

| 场景 | 操作及应见现象 |
| --- | --- |
| `sneak_cat`、`sneak_ocelot`、`sneak_rabbit` | 生存玩家分别站立/潜行接近；站立触发原生逃跑，潜行不触发对该玩家的避让。另一个站立玩家仍可触发；受伤惊慌仍保留。禁用后恢复原生避让。 |
| `stagger` | 六个同种骷髅自然取得同一铁傀儡目标；拉弓开始错开，仍各自真实射箭，不能无限等待。不同目标/不同种类不协同；不缩短原生拉弓时间。 |
| `blindness`、`nausea` | 生存玩家从远处走近，发现距离缩短；失明优先。反胃箭有偏差。实际伤害引起的报复仍可索敌，玩家自己射箭保持原版。 |
| `invisibility`、`crouching`、`crawling` | 在同一距离比较站立、潜行、干地爬行、带装备隐身；潜行/爬行/隐身降低主动发现距离。爬行须用原生低顶棚进入姿态，游泳不当作干地爬行。隐身保留原生装备可见度。 |
| `glowing` | 发光生存玩家在墙后有限距离内可被发现；骷髅不能穿墙发箭。移除墙后才能射击。给射手失明后，不靠发光绕过限制；创造/旁观不成为敌对目标。 |
| `movement`、`obstacle`、`hazard` | 实际走射横移；单格安全障碍可起跳，门/栅栏/低顶棚不强跳。检查火、熔岩坑、细雪、悬崖；目标退出后不遗留横移。不可把向脚下倾倒熔岩当作横移探路失效。 |
| `melee` | 查看真实命中间隔；疲劳增加、急迫减少，下限 6 tick，上限 200 tick。原生受伤冷却保留，并非每次挥手都能扣血。 |
| `high_target` | 困难难度，生存玩家站在夹具高台边缘，近距离且高于僵尸眼睛约 0.26 格；原生调度触发物理跳跃。平地、水中、骑乘、无视线、禁用不额外起跳。 |
| `evoker` | 生存玩家近身触发原生逃跑，近距离速度系数 .8、远距离 .4；施法时不同时执行逃跑导航，创造后退出。速度/目标修正两个配置独立。 |
| `swim` | 观察持三叉戟溺尸实际游泳，身体按游泳量向约 -80° 过渡、头部俯角；成人/幼体手持位置与层模型正常。禁用恢复原生 -10° 姿态，不改变三叉戟伤害。 |
| `burn`、`freeze` | 对应橙色/浅蓝色身体染色；真实着火或完全冰冻才生效。受伤闪红及原生伤害保留；禁用只取消自有颜色，不熄火/解冻。 |
| `burn_arrow` | 生存玩家成为目标，使持弓燃烧骷髅发出真实燃烧箭，观察追加火焰粒子。至多每 4 tick 一粒；禁用追加粒子后箭的燃烧/伤害仍保留。 |
| `vex` | 用普通弓命中恼鬼，正值投射物伤害进入原生护甲前乘 3；近战/普通非投射物不放大，禁用恢复原生。夹具铁头盔影响最终扣血，不能仅比较裸装理论值。 |

额外回归：门盾位置、五种幼年骷髅半体型/弓与护甲位置、备用木剑死亡不大量掉落；职业弩主副手、渔线、幻术师箭与骷髅马姿态。把截图、`check` 输出、具体配置/标签与可复现步骤一同记录。多人、整合包和长期性能另记结果，不从本清单的自动测试推导通过。

整 E4 验收后才讨论下一批；本轮不启动 Boss、R5、Phase 2 或 Phase 3。
