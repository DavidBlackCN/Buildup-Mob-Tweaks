# 完整 R4 统一实机验收清单

R4-A/B 已收到用户实机反馈；本清单用于在当前组合产物中复测 A/B/C/D，不改写历史结果。手工验收目前 NOT RUN；剩余 68 个非生效旧 ID 见 [台账](R4_REMAINING_AUDIT.md)，不要将其配置默认 true 视为已迁移。不进入 R5/S3。

## 共用环境

Minecraft 26.3 / Java 25 / Fabric Loader 0.19.5 / Fabric API 0.162.0+26.3 / Fzzy Config 0.7.7+fix3+26.3 / Fabric Language Kotlin 1.14.1+kotlin.2.4.20，可选 Mod Menu 21。只装一份当前 build/libs/buildup-mob-tweaks-1.0.0.jar，在独立测试世界验收，保存日志。先普通难度、夜间、28×28 平坦场地；生产世界/旧 S2 数据迁移及领地兼容本轮未验证。

生存玩家吸引真实目标；创造模式先布置，再切生存。生物应 `PersistenceRequired:1b`，不要 `NoAI:1b`；观察目标阶段时 `/buildupmobtweaks <pillager|skeleton|zombie|drowned|raid|remaining> <选择器>`。诊断权限按各命令实现；`/data get entity` 查看附件冷却/出生选择。退出检查用创造、旁观、遮挡、超距分别复测，再切回生存检查重新索敌。

单项禁用例：`/tag @e[tag=r4d_b,limit=1] add buildupmobtweaks:disable_blaze_orbit`；恢复 `remove`。整组回退：添加 `buildupmobtweaks:vanilla_ai`。Fzzy GUI 总开关及 hostile 分组内对应字段分别关闭，在实际服务器验证其他功能仍可用，保存后重启检查关闭值仍保留。数据包实体类型排除标签另测。

## R4-A 骷髅系列

- [ ] 普通骷髅持弓，夜/昼、屋顶/露天、2～3/12～18 格之间移动；等待 30～60 秒，确认实际主手换剑/弓、走射/蓄弓和箭，不只有动画。
- [ ] 近战状态杀死多只：生成备用木剑不掉落；原弓与人工放入的带名字/耐久/附魔真实外部剑仍按原掉落策略，保存重启后复测。若旧无来源木剑，与 [历史歧义](R4A_SWORD_FIX.md) 对照，不推定其真实来源。
- [ ] 流浪者在近距无弓定向条件下翻转/雪球；沼骸逼近时闪避、毒云实际中毒；特定条件与命令沿用 [R4-A 原清单](R2B_REBUILD.md)，等待窗口 30～60 秒，默认/强制条件分开记录。
- [ ] 放置可达/不可达屋顶、切换各独立开关；恢复攻击且无目标/物品复制。骑乘、细雪转化的物品组件守恒复测。

## R4-B 僵尸、尸壳、溺尸

- [ ] 使用自然/刷怪蛋出生取样门盾/幼体；定向夹具按 [R4-B 原清单](R2C_REBUILD.md)，将定向成功与默认频率分开。门盾正面 10° 阻挡、侧后命中、盾材耐久耗尽；原装备不被删除、幼体最多一个，不补发。
- [ ] 已有副手盾的普通僵尸实际举盾、耗耐久、结束防御并攻击；禁用恢复原版。
- [ ] 尸壳与生存目标距离 >12 格、至少三层沙，观察下沉→按目标快照换位→上浮；切创造/旁观、禁用、移除沙、mobGriefing=false、保存重载均回到地表正常物理。
- [ ] 溺尸持真实带名字、耐久三叉戟，岸上/水中投出、碰撞伤害、寻回原件；逐阶段死亡/保存/目标退出/超时/玩家拾取，无手持+弹体双份、无丢失后补发。

- [ ] **恶魂**：开放空中场地，`/summon minecraft:ghast ~ ~8 ~ {Tags:["r4d_g"],PersistenceRequired:1b}`，生存目标相距约 20～30 格；等待 20 秒。实际张嘴/轻微膨胀闪色、约 2 秒蓄力、约 5 秒安静期、约 7 秒连续发射间隔，慢弹仍可原版反弹。三项分别关闭，较长冷却关闭恢复原版前摇。墙遮挡/NoAI/创造退出后视觉清空，恢复重新完整蓄力。
- [ ] **烈焰人**：`/summon minecraft:blaze ~ ~ ~ {Tags:["r4d_b"],PersistenceRequired:1b}`，9～16 格生存目标，等待 20 秒；观察真实可见小火球半环固定序号、约 2 秒持有后向当前目标释放，实际命中；三难度 2/3/4，难度弹数关闭恢复三枚，orbit 关闭原版直接飞行而非粒子假弹。横移关闭仅取消横移。创造/旁观/禁用/死亡/中途保存加载清理旧弹，不清理外部乘客，不掉生成火焰弹。
- [ ] **蠹虫**：不可寄生地板（黑曜石）、`/summon minecraft:silverfish ~ ~ ~ {Tags:["r4d_f"],PersistenceRequired:1b}`，一次轻伤、生存攻击者活着，等待 15 秒；实际跳起、落地隐身侧移、恢复可见/普通移动；隐藏中仍能受伤。旁放一个虫蚀石，mobGriefing 与 block_drops=true，观察躲藏结束后原版求援释放同伴；停步关闭可移动求援，粒子关闭仍释放。主手铲直接近战易伤两倍，其他武器/投射物无该倍率；独立禁用/重载恢复。普通石地板上的原版钻块另观察，不混作躲藏技能。
