# 袭击战斗（S2 / 26.3）

本文件保留 C1 基础策略并同步 S2 变化；新增火球、图腾、跳投、船只等见 [S2_COMBAT](S2_COMBAT.md)。历史验证见 S2C1_REPORT，当前验证见 [S2_REPORT](S2_REPORT.md)。

## 配置与行为

当前配置 v8，既有路径 hostile.raid；七个开关默认 true，受 general.enabled 控制，不依赖 Traits。这里是基础装备/角色策略与频率限制，没有概率强化或额外随机高级技能。

| 开关 | 行为与关闭方式 |
|---|---|
| pillagerRetreat | 主手原版弩、可见目标距离 ≤4 格、在陆地且非骑乘时，沿目标反方向退让。复用脚下完整支撑/空气/危险地面检查；关闭后交给原版走位 |
| pillagerWeaponSwitch | 仅已有原版弩和七种原版斧的双手组合：≤3 格换斧，≥6 格换弩，20 tick 冷却。转移原 ItemStack 引用与各自掉率，不复制弹药或武器；关闭保留当前手槽并恢复原版弩判断 |
| vindicatorSupport | 无有效目标时，每 20 tick 查看 8 格内最多 8 名友方唤魔者/女巫，接手其最近 100 tick 内伤害来源；攻击者须可攻击、可见且在 16 格内。不抢已有目标；关闭仅清除本功能仍持有的目标 |
| evokerVexLimit | 原版一次召唤三只前，预留完整三只容量；查询跨区块/维度的持久所有权索引，卸载仍占名额，实际施法前复查。关闭保留已有恼鬼和原版随机召唤规则 |
| evokerSummonCooldown | 保留原版召唤 Goal、声音/施法前摇，加持久世界时间冷却；关闭恢复原版间隔检查，不取消已有实体 |
| witchWindup | 原版选完药水后，用该药水的 ItemParticleOption 粒子预告；延迟发射同一物品与原版工厂。前摇不向手槽放可掉落物品。喝药、目标改变/死亡、视线受阻、离开 16 格或关闭时取消；保留原版向 Raider 治疗的目标清空语义 |
| witchThrowCooldown | 为已受理投掷保存最小间隔，含治疗同伴。与前摇独立；关闭仍可保留前摇，关闭前摇仍可保留频率限制。原版 Goal 检查周期可能使实际间隔更长 |

| 数值 | 默认 | 范围与生效时机 |
|---|---|---|
| vexLimit | 6 | 3–24；立即影响新检查；必须能容纳完整三只。调低不删除现有恼鬼 |
| summonCooldown | 680 tick | 340–2400；新施法采用新值，已有截止时间保持 |
| witchWindupTicks | 20 tick | 10–60；仅新前摇 |
| witchCooldownTicks | 100 tick | 60–400；仅新投掷，已有截止时间保持 |

20 tick 约一秒。直接编辑 TOML 需停服重启；GUI 按 Fzzy 权限和同步生效，不假定 /reload 重读配置。

## 持久化、兼容与资源边界

附件 buildupmobtweaks:raid_combat 的 version=1 保存 next_summon_at、next_potion_at；不含备用物品、生成许可或 Raid 成员信息。旧实体第一次加载获得空冷却，未知未来版本原样保留、附加行为停用。女巫前摇与目标引用不持久化，卸载/重启取消未发射药水；冷却仍保存，不通过重载刷投药频率。

掠夺者不凭空获得斧，当前僵尸系装备池也未扩展到袭击成员。管理员/数据包配装已有双手物品后才发生切换。未知第三方弩/斧不由本功能接管；它们原有 AI 由原版或其 Mod 决定，不宣称通用 Adapter 兼容。

恼鬼现改为世界持久 UUID 所有权索引：不强加载区块，真实销毁释放，卸载不释放。升级前未再加载的旧恼鬼首次加载才登记，不能追溯未读取的历史实体；见 S2_COMBAT/S2_REPORT。

药水预览现在同时使用同步附件驱动的客户端手持模型和粒子；不会把预告物品写入实际手槽或掉落。取消时清理，原版药水选择仍保留。S2 跳跃自饮与跳投是另外两个开关；视觉辨识仍待人工验收。

四个 Mixin 分别围绕 Mob.serverAiStep、RangedCrossbowAttackGoal、EvokerSummonSpellGoal 和 Witch.performRangedAttack。弩停止 Goal 时只在本功能已转入斧模式且目标仍有效的情况下保留目标，避免原版 stop 清除目标后近战失效。Mixin 与外部重写同一方法/工厂的 Mod 可能冲突；开关不等于卸载注入，需要按具体组合启动验证。

## mobGriefing、领地与多人性能

C1 基础策略不改地形；S2 新增火球防点火与其他环境机制的边界见 S2_COMBAT。没有改变 Raid 波次、胜败规则。第三方领地保护仍需具体组合测试，不能以 mobGriefing 检查代替兼容验收。

卫道士支援仍为20tick、8格、最多8候选；恼鬼使用世界索引，不再进行附近计数扫描。S2 其他目标查询均限制半径、频率和返回数量，详见 S2_COMBAT。多人压力/MSPT仍待验收。

## 诊断与人工复现

`/buildupmobtweaks raider <单个实体选择器>`：等级 4 的只读查询，输出 UUID、完整保存冷却、待投药水和七个当前门控。可对唤魔者、女巫、掠夺者、卫道士使用；不修改 Raid。门控显示配置值，未知版本附件的实体仍会停用附加策略。

1. 在备份世界给掠夺者主手原版弩、副手原版斧，持有可攻击目标；分别在 2 格、8 格附近测试近战和恢复射击，核对命名、耐久、已装填弹药及掉率。关闭开关不丢装备，不应丢失有效目标。
2. 只给弩，将目标放在 3 格处；平地应退让，背后缺口/危险方块/障碍不得继续主动后退。
3. 卫道士无目标时攻击附近友方唤魔者/女巫，观察它支援；已有目标时不抢目标。关闭后回到原版目标选择。
4. 唤魔者保持原版前摇；附近自有恼鬼达到配置容量后不再新增。间隔内卸载/重载不能重置冷却；不同唤魔者分别计数。
5. 女巫分别攻击远近目标和支援受伤袭击同伴，观察药水粒子、延迟及降低频率；前摇中换目标/挡视线/关闭选项不应有迟到投掷。核对普通药水效果和原版喝药行为。
6. 单机与至少两名玩家的专用服务端实际触发完整袭击，完成所有波次、击杀和胜利；对照七开关逐项关闭。测试 mobGriefing true/false、拟使用的领地/优化/AI Mod 与 GUI 同步。

自动证据和未运行项见 [S2-C1 报告](S2C1_REPORT.md)。独立持久化脚本 `.\scripts\Test-RaidPersistence.ps1 -AcceptEula` 使用 JDK25、已接受 EULA 的唯一世界与 127.0.0.1:25590，不覆盖旧世界。

> C1 中不新增火球/地形操作的描述仅适用于当时基础策略，S2 扩展的规则以 S2_COMBAT 为准；恼鬼计数已不再采用附近扫描。
