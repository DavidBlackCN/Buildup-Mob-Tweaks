# S2 统一人工验收清单

适用：26.3 / Fabric / Java 25，S2-A～D。自动测试与启动结果见 [S2_REPORT](S2_REPORT.md)；以下项目尚未代替用户实机验收。使用备份或新测试世界，先普通难度，再补困难难度。

稀有技能可在配置里把对应概率临时设为 1000、同实体其他高级概率设为 0，再生成**新个体**；旧个体不重抽。用 `/buildupmobtweaks s2 <实体>`、`skeleton`、`zombie`、`raider`、`vex` 查询，不要仅凭一次未触发判失败。配置位置及条件见 [S2_COMBAT](S2_COMBAT.md)。测试后恢复概率。

| 验收 | 操作与期望结果 | 失败现象 |
|---|---|---|
| [ ] 配置与同步 | 中英文查看扩展开关；选一项关闭/开启；独立服由 OP 修改，普通玩家不能改；重启保留 | 缺失翻译、开关串联、客户端覆盖服务器 |
| [ ] 骷髅系 | 弓/副手弓与近战切换，高低目标瞄准，狙击寻遮蔽；流浪者跳射/下落弹幕、沼骸、Parched、凋灵骷髅逐项试用 | 丢目标、永久横滑、弓失效、无前摇连发 |
| [ ] 僵尸与骑乘 | 实际盾牌/木门格挡；尸壳在三层连续沙地下潜，中断或重载回地表；马/鸡冲锋和一次史莱姆投掷 | 穿墙滞留、长期无碰撞、无限补坐骑/史莱姆 |
| [ ] 装备守恒 | 溺尸至少三轮投戟/回收/超时拾取/死亡；钓竿牵引消耗耐久；僵尸职业武器与原有装备保持 | 三叉戟或武器复制、满手被覆盖、无限补发 |
| [ ] 袭击全流程 | 完成一场自然袭击；观察掠夺者退让/换斧/破盾、脱战吃食物、卫道士支援、海上船只 | 波次卡死、抢玩家船、物品丢失、持续报错 |
| [ ] 唤魔者与恼鬼 | 火球先预警且不点火；图腾只用一次、其他施法可击杀；恼鬼冲刺可躲且结束停顿；卸载后仍占名额 | 永久无敌、重复图腾、卸载绕过召唤预算 |
| [ ] 女巫与幻术师 | 女巫手持预告与实际药水一致、高处跳投；幻术师额外箭有上限、换位不进实心方块 | 空手预告失真、取消后幽灵药水、额外箭可刷取 |
| [ ] 其他敌对生物 | 末影人连击有预警；恶魂慢弹/冷却；烈焰人三难度弹数；旋风人困难风爆；蠹虫求援/钻块 | 无冷却、弹体无限存活、禁用后仍持续技能 |
| [ ] 环境与视觉 | 对照失明/发光/潜行、休息受伤和声音苏醒；查看恶魂、溺尸、副手弓和图腾动画；`mobGriefing=false` 复查钻沙/寄生/风爆 | 穿越保护规则、动画错手、永久休眠 |
| [ ] 存档与退出 | 单机及真实双人独立服各一轮，战斗中换目标、卸载/重启/死亡，查看日志 | 崩溃、重复抽签、冷却清零、重复掉落 |

统一放行条件：无上表失败现象；发现问题记录实体、配置、场地、日志和复现步骤。第三方领地/AI/动画 Mod 与高密度性能属于额外兼容验收，不以本清单自动通过。Boss、Villager Intelligence、新附魔不属于 S2，当前停止于 S2。
