# 骷髅战斗（S2-A）

只处理原版 skeleton、stray、bogged，服务端权威。独立重设计，不复制 Mob AI Tweaks 代码。保留原版目标选择、接近导航、拉弓节奏、弹道速度、伤害、箭矢工厂和特殊箭；不增加装备、箭矢奖励或附魔。

## 配置与行为

配置版本 4；`hostile.skeleton` 下七项布尔值默认 true，均受 `general.enabled` 控制。前三种高级能力还受 `traits.enabled` 控制。关闭后停止该能力，保留已有物品和特性结果；修改概率只影响以后出生的实体。磁盘 TOML 应停服编辑再启动，`/reload` 只重载数据包。

| 选项 | 实际范围与回退 |
|---|---|
| safeStrafing | 对原版弓 Goal 的横移进行同高度落脚检查；不安全时尝试反向横移或停止横移，射击照常。检查半格/一格处四个脚印角、支撑面、两格空气，拒绝流体、障碍及岩浆块/营火。关闭保留原版横移参数。不是全局导航安全保证，台阶等复杂地形可能保守停步。 |
| targetValidation | 清除内部保存的死亡、同队、跨世界或不可攻击目标，停止对应使用动作和导航；由原版目标 Goal 重新选择，不扫描候选、不扩大仇恨范围。不宣称修复 MC-121706。 |
| weaponSwitching | 仅现有两手恰好为受支持弓和原版七种剑时切换。目标在 3 格内用剑，6 格外用弓，中间保持，冷却 20 tick。交换原 ItemStack 引用及各自掉率，不创建/补发/克隆物品。关闭恢复原版持弓判断，可能使用副手弓；不把装备强制换回。 |
| bowCompatibility | 共用装备能力识别支持 BowItem；让它进入原版弓 Goal、使用正确手和弹药能力检查。未知非 BowItem 不获虚构能力，继续原版近战/外部 AI。测试注册的 BowItem 实例可连续射击，但不代表支持各 Mod 的自定义射击协议。关闭使用原版精确弓 ID 判断。 |
| skeletonSniping | 已抽中特性的骷髅在地面、遮蔽处、可见目标距离 10–15 格、拉弓至少 10 tick 后出现暴击粒子；本次射击散布最多 1，之后恢复原版，冷却 160 tick。不增伤、不寻找掩体。 |
| strayJumpShot | 已抽中特性的流浪者在地面、头顶空间足够、可见目标距离 6–12 格、拉弓至少 10 tick 后出现粒子并起跳；仍在空中的本次射击散布最多 1，冷却 160 tick。保留原版迟缓箭。 |
| boggedSporeRetreat | 已抽中特性的沼骸遇 4 格内可见威胁时出现孢子粒子、按安全落脚检查后撤；20 tick 前摇后，仅对同一个仍在 3 格内可见且可攻击的目标施加 40 tick 中毒，冷却 240 tick。不创建持续范围云、不攻击旁观者、不产蘑菇或战利品。保留原版毒箭。 |

水中、骑乘和未落地时不启动高级能力。前摇中失去目标、换目标、丢失视线、失去弓、关闭对应功能都会取消；冷却已在前摇开始时记入存档，不退还。精确射击前摇最长保留 30 tick；仅消费一次。伤害与效果仍走原版系统；未验证领地保护 Mod 对效果的拦截。

`safeStrafing=false` 不取消沼骸技能自己的安全后撤；关闭 `boggedSporeRetreat` 才关闭该技能。这两者独立。没有全局实体查询；每次原版横移最多三组、每组八个落脚点。高级能力只检查当前目标，无多目标列表或每 tick 重建 Goal；仅装备变化或开关状态变化时重新评估原版武器 Goal。

## 特性和存档

- `skeletonChance=70`、`strayChance=70`、`boggedChance=10`，均为 0–1000 千分概率，对应 7%、7%、1%。每个实体只有自身物种的一项候选，不叠加其他物种能力。
- 使用 Fabric 持久 attachment `buildupmobtweaks:skeleton_trait`，数据版本 1，字段为 version、origin、status、trait、level、exclusive_group、next_special_at。等级 2 对应两种精确射击，等级 3 对应沼骸稀有技能；互斥组均为 skeleton_special，等级仅作分类。独立于 S1-B 的诊断 marker 数据，受同一 Traits 总开关约束；两者均不更改属性数值。
- 仅明确新出生来源抽取一次。已有存盘实体、未知来源、无源转换、跨维度来源不补抽。关闭功能或概率为零时出生的实体记录 none，重启/修改概率不补发。
- 转换继承来源记录；骷髅转流浪者不会再次中奖，原骷髅特性在新物种上不激活。未知版本原样保存且不激活。
- `next_special_at` 使用该世界游戏时间，随存档保留；运行期前摇不会保存，卸载会取消但不抹去冷却。跨世界时间差可延长冷却，未专门验证该场景。手持切换冷却是短暂运行状态，重载不复制物品。
- 等级 4 只读诊断：`/buildupmobtweaks skeleton <单个实体选择器>`，显示 UUID、完整记录、active 和七项开关；`equipment` 显示两手当前能力。

## 可复现对照与人工步骤

自动场景位于 `SkeletonTests.java`。执行 `./gradlew.bat build -PtestEula=true` 可重跑；单独持久化复现：`./scripts/Test-SkeletonPersistence.ps1 -AcceptEula`。没有录像，以下步骤供人工验收。

1. 创建备份测试世界，在平坦有屋顶的 16×16 场地放置三种生物及可攻击目标。先把三项 chance 设为 0，再生成实体；用 skeleton 查询确认 none，观察连续原版弓射击，流浪者/沼骸保留原版特殊箭。
2. 停服把三项 chance 设为 1000，重启后生成新实体，查询确认各自特性。骷髅遮蔽处保持 10–15 格，流浪者保持 6–12 格并留头顶空间，沼骸接近到 4 格。观察粒子、起跳/后撤及 8/8/12 秒冷却。旧 none 实体不应补抽。
3. 逐个关闭七项开关，只观察对应行为回退。重新开启高级特性不应改写既有 trait；traits.enabled=false 只停高级特性，基础武器能力仍可工作；general.enabled=false 回到原版战斗判断。
4. 用原版 `/item replace entity` 给同一实体主手弓、副手剑，记录命名、耐久、数量与掉率；分别靠近 3 格、远离 6 格，观察切换及 1 秒防抖。移走一件物品后不得补发；死亡掉落应沿原槽位策略，不能复制。原版拾取仍取决于 CanPickUpLoot 与原版规则，本 Mod 不强行启用。
5. 在横移侧边造落差、放岩浆、竖墙，观察是否停止或换向且继续射击；再在台阶、水、骑乘和狭窄地形测试。新逻辑只保护弓 Goal 的局部横移/孢子后撤，不改原版追击寻路。
6. 沼骸前摇中退出 3 格、遮挡视线或换目标，应取消中毒且保留冷却；同队目标和旁观者不应被技能波及。未测试真实保护 Mod，不把此结果称为保护插件兼容。
7. 单机及独立服务端各检查中文/英文新字段、权限、同步和粒子观感。真实第三方弓/AI/优化 Mod 必须记录具体版本再验收。
