# 僵尸系战斗（S2-B / Minecraft 26.3）

独立实现，不复制上游源码或素材。所有行为服务端执行；不注册新实体、物品或附魔。保留原版近战、目标选择和装备池一次性分配。当前配置 v8，原数据附件仍为 v1；新骑乘/职业/钓竿规则见 [S2_COMBAT](S2_COMBAT.md)。

## 僵尸与尸壳

| 配置 hostile.zombie | 默认 | 生效范围 |
|---|---|---|
| shieldUse | true | 成年僵尸/尸壳实际副手原版盾牌，3 格内可见目标，格挡 15 tick、基础冷却 80 tick；不要求高级特性 |
| doorGuard / doorChance / doorCooldown | true / 30 / 60 | 出生木门防御特性；副手恰好一扇 wooden_doors Tag 物品，正面 60° 内命中可挡，第三次消耗门 |
| activeGuard / guardChance / guardCooldown | true / 70 / 100 | 出生主动格挡特性，实际副手盾牌，8 格内可见目标，格挡 30 tick |
| sandBurrow / burrowChance / burrowCooldown | true / 30 / 200 | 仅成年尸壳，双方脚下为 SAND Tag，距离 5–12 格、高差 ≤0.5；三层连续沙地且 mobGriefing 开启；15 tick 前摇、20 tick 下潜，前进最多 3 格 |
| babyRider / riderChance / riderCooldown | true / 10 / 200 | 仅幼年普通僵尸，骑现有 4 格内可见成年普通僵尸；最多三次尝试，成功后不再寻找 |

Chance 为 0–1000 千分权重。适用的四种高级能力共用一次互斥抽取，总和低于 1000 的空余为 none，超过则归一化；不是四次独立中奖。成年人不抽幼年骑乘，普通僵尸不抽尸壳沙地能力。等级为高级 2、幼年骑乘 3，互斥组 zombie_special；原 S1-B 诊断标记仍无战斗效果。四个开关还受 traits.enabled 控制；基础盾牌及三叉戟不受此开关控制。

Cooldown 单位 tick（20 tick 约一秒），上限 2400，下限依次为门 20、主动格挡 40、沙地 60、骑乘 40。动作开始预占持久冷却；改值不缩短已保存截止时间。未知数据版本保留且不执行。加载、转换、维度移动和未知来源不重抽；转换保留原记录，仅兼容物种能执行。

木门只能挡具有直接伤害实体及来源位置的正面命中，BYPASSES_SHIELD、背后和环境伤害不挡。门不是注册的新盾牌，不提供特殊渲染；云粒子反馈阻挡。关掉门防御后保留门和已消耗次数。主动格挡结束释放自身的使用动作，允许原版近战继续；关闭高级格挡仍可由独立基础盾牌功能接管近距离格挡。

S2 已补全地下轨迹：路线下三层连续沙、地表空间，mobGriefing=true 才启动；前摇后暂时接管重力/碰撞，下潜最多 2.2 格。仅 IN_WALL 免伤，其他伤害有效。目标变化、条件失效或重载恢复记录地表与正常物理，冷却保留，不挖方块；出口边界见 S2_COMBAT。

幼年骑乘每 20 tick 错峰尝试，单次最多检查 8 个候选，冷却限制重试；不生成、删除或叠加坐骑。关闭后在下一次 AI tick 只解除本功能记录的骑乘，不干预其他来源的骑乘。

## 溺尸三叉戟

| 配置 hostile.drowned | 默认 | 生效范围 |
|---|---|---|
| tridentConservation | true | 将实际主手恰好一把原版三叉戟转移给唯一原版投射物；空手不凭空发射 |
| tridentRecovery | true | 优先步行/游泳回收自己的落地、命中过或水中减速投射物；32 格内导航、每 10 tick 重算路径 |
| tridentPlayerPickup | true | 超时释放的原武器按出生/拾取时的原基础掉率仅判定一次；通过后允许玩家拾取 |
| recoveryTimeout | 200 | 40–1200 tick，仅新投掷使用新值；离线/未加载期间按世界 gameTime 截止时间处理 |

三者是独立门控；没有守恒投掷就不会新增可管理归属的投射物。关闭守恒只恢复后续原版投掷，已建立的事务继续安全收尾；关闭回收停止寻路/重新装备，关闭玩家拾取也屏蔽已释放投射物。总开关关闭后仍保留必要的去重/超时清理，不删除现有装备、不凭空补发。重新开启玩家拾取沿用原判定，不重新抽掉率。

物品所有权只能是主手、投射物、玩家/原版掉落实体之一。附件只保存 UUID、截止时间和原掉率，不保存备用 ItemStack。连续投掷时从空手或尚有事务的实体拒绝合成第二把。生成失败归还原手中物品；回收先移除原投射物，再转移实际物品到空手，保留组件、耐久、名字、原版附魔与掉率。手里已拿到其他物品则不覆盖它。

回收目标不会替换战斗目标。投射物至少飞行 10 tick 且落地/命中过/水中减速，近至 1.5 格并有视线后才转移。忠诚附魔保留在物品上；仅本功能归属投射物禁用原版忠诚自动返回，因为原版到达非玩家主人后会丢弃投射物而不重新装备。玩家与未标记的原版投射物不受影响。

主人正常死亡且原投射物仍在当前服务端加载、主手为空时，在原版掉落遍历前归还武器：沿用原版击杀判定、抢夺、消失诅咒和装备掉率，仅结算一次。主手已被外部物品占用时保留该物品，原投射物按一次基础掉率释放。mobDrops=false 或消失诅咒不会允许该释放物成为可拾取战利品。

**卸载边界**：不强载区块，不跨维度搜索，不创造丢失的投射物。主人/投射物分别卸载，或主人死亡时投射物未加载，无法在原死亡事件即时归还；投射物加载后按原截止时间和基础掉率收尾，不能补算原击杀的抢夺加成。未通过释放判定的投射物不可回收或拾取，交给原版消失流程。掉入虚空/被外部删除不会补发。此边界有意优先防复制，不宣称任何外部 Mod 改写装备/投射物都无损。

## 装备与诊断

默认内置池仍以 10% 尝试给新成年僵尸/尸壳/溺尸的空主手木剑，不暗自增加盾牌/木门。可用 [已有数据包](../examples/equipment-demo/README.md) 提供副手盾牌，或将其物品 Tag 改为 minecraft:oak_door。池与高级特性分别抽取；给木门不保证获得门防御特性。无新武器资源，也没有新增附魔玩法。

`/buildupmobtweaks zombie <单个实体选择器>`（权限 4）显示 UUID、zombie_trait、trident_flight、owned_trident 及八个当前开关，亦可查询三叉戟实体；这是只读原始诊断，不把持久 trait 字段等同当前正在执行。冷却、门使用次数、骑乘尝试/坐骑 UUID 随实体保存。

## 复现与人工验收

1. 在备份测试世界，将指定高级能力 Chance 设 1000、同物种其他 Chance 设 0；只召唤新实体。给成年僵尸副手原版盾牌/单个木门，对照关闭独立开关，检查正面、背面、冷却、第三次消耗及近战恢复。
2. 双方站在连续平坦沙地，距离 8 格；观察尸壳前摇和换位；加入墙/沙地缺口或中途换目标，确认不穿越。
3. 配置幼年骑乘 1000，召唤幼年普通僵尸和现有成年普通僵尸；确认无新增坐骑，关闭后解除本功能骑乘。
4. 给溺尸一把命名、有耐久损失的三叉戟，在陆地和浅水中保留同一目标，观察至少三轮投掷/回收。超时后确认按掉率拾取，死亡与重新入服不复制。
5. 联机由 OP 修改配置，普通玩家观察生效；检查 Fzzy 中英文布局和同步。高密度、复杂深水、真实自然群体刷怪/不同规则刷怪笼、跨维度与第三方 AI/保护项目另行验证。

自动验证命令和明确未运行项见 [S2-B 报告](S2B_REPORT.md)。Windows PowerShell 7 下可执行 `.\scripts\Test-ZombiePersistence.ps1 -AcceptEula`（先设置 JDK25，已同意 EULA），使用独立 127.0.0.1:25589、唯一测试世界，正常 stop 并保留证据。
